## ✨ Core Highlights

- **23 Structurally Distinct Public Themes**: Not merely color swaps—each theme features dedicated layouts, typography stacks, DOM structures, and signature interaction mechanics (from 3D WebGL to terminal command prompts to paper collage).
- **"Intelligent Stage" Admin System**: Pixel-crafted telemetry center with 3 glass metric modules, SVG gauges, animated channel network topologies, and ambient motion controls.
- **WYSIWYG Visual Site Editor**: Canvas editor with live responsive device previews (Desktop, Tablet, Mobile), instant drag-and-drop block ordering, and design system token overrides.
- **Full-Spectrum Headless CMS**: Built-in managers for Projects, Markdown Case Studies, Blog Articles, Testimonials, Experience Timelines, and Skills.
- **Recruiter Mode & Interactive Resume**: Instant recruiter-targeted view with skill endorsement matrices, project highlights, and one-click PDF generation.
- **Zero Backend Required**: Fully functional in-browser with persistent LocalStorage state, JSON database migration import/export, and zero complex server setup.

## 🚀 Quickstart & Installation

### Prerequisites
- **Node.js**: Version `18.0.0` or higher (Node 20+ recommended)
- **Package Manager**: `npm`, `pnpm`, or `yarn`

### 1. Clone the Repository
```bash
git clone https://github.com/smhrimmy/pdl-portfolio-os.git
cd pdl-portfolio-os
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Launch Development Server
```bash
npm run dev
```
Open your browser and navigate to:
```
http://localhost:5173
```

### 4. Build for Production
To generate an optimized production bundle:
```bash
npm run build
```
To test the production build locally:
```bash
npm run preview
```

## ⚙️ Customization & Personal Data Guide

### Updating Personal Information
All core portfolio content is located in clean, typed data files in `src/data/`:
- **Bio & Social Links**: `src/data/mockProfile.ts`
- **Projects & Case Studies**: `src/data/mockProjects.ts`
- **Blog Articles**: `src/data/mockPosts.ts`
- **Testimonials & Endorsements**: `src/data/mockTestimonials.ts`
- **Career Timeline & Skills**: `src/data/mockExperience.ts` and `src/data/mockSkills.ts`

### Modifying or Adding Themes
All 23 themes are cataloged in `src/themes/`:
- Each theme is a modular React component in `src/themes/Theme*.tsx`
- Registered in `src/themes/themeDefinitions.ts`
- Any custom theme automatically receives full support across the Theme Selector, Visual Editor, and floating previewer.

### Exporting and Restoring Data
1. Navigate to `/admin/backup`.
2. Click **Export All Data (JSON)** to download a complete snapshot of all edits made in the admin panel.
3. Import the JSON snapshot on any device to immediately restore your custom portfolio state.
